01 / 纤维丝配置

支持3–20根不同力度的纤维丝；自动按从小到大排序。请使用标称或校准后的实际力度，不能使用手柄编号。

02 / 标准停止规则

X = 有缩足（下次降一级）
O = 无缩足（下次升一级）
首次出现 OX / XO 后，再刺激4次即结束。
一旦需要比最低更低或比最高更高的力度，标记为越界；不能擅自重复边界力度并继续计算。

完整公式与变量定义

本站统一以克（g）为力度单位。先将输入力度转换为 log₁₀(g)，再分别计算 exact δ、高精度 k 与 Chaplan/Dixon 三位小数表 k。

1 / 对数力度与平均间距

xj = log10(Fj)
δj = xj+1 − xj
δ̄ = (xm − x1) / (m − 1)

若所有 δj 相同，则纤维丝在对数尺度上等距；左侧配置区同时报告平均 δ、相邻 δ、几何倍率及最大相对偏差。

2 / Chaplan/Dixon 表 k

PWTtable = Flast × 10(ktable · δ̄)
  • Flast：序列最后一次刺激力度（g）。
  • ktable：Dixon 最大似然表的三位小数系数。
  • XOOOOO 使用 Dixon 的 −0.893；Chaplan 附录的 −0.983 仅作为印刷笔误展示。

3 / 本站高精度 k

kHP = θ̂ − jlast
θ̂ = arg maxθ Σ [ I(Xi) ln Φ(ji−θ) + I(Oi) ln(1−Φ(ji−θ)) ]
PWTHP = Flast × 10(kHP · δ̄)

ji 是刺激级别索引，Φ 是标准正态累积分布函数。高精度列不先舍入 k，因此与三位小数原表会有轻微差异。

4 / Christensen exact δ（主结果）

μ̂ = arg maxμ Σ [ I(Xi) ln Φ((xi−μ)/d) + I(Oi) ln(1−Φ((xi−μ)/d)) ]
d = (xhigh − xlow) / (jhigh − jlow)
PWTexact = 10μ̂

exact δ 使用本轮实际访问的力度及局部对数间距，更适合不完全对数等距的纤维丝配置。

5 / 解释边界

这里的“exact”表示按实际力度建模，不代表生理真值。三套输出都是模型点估计，不提供单只动物的置信区间；算法假设各次刺激条件独立且反应分布稳定。
